Справка и параметры URL

Руководство по сервису, синтаксису ссылок на события и интеграции с календарями Google, Apple, Outlook и iCal.

1. О сервисе

CalendarFactory: лёгкая 100% клиентская Edge-утилита для моментального создания прямых ссылок на добавление событий в календарь. Все параметры кодируются прямо в URL. Нет бэкенда с базами данных, нет cookies и сторонних систем отслеживания.

Без регистрации и баз данных

Все данные о встрече хранятся в самой ссылке. Сервис ничего не записывает и не хранит на серверах.

Кросс-платформенность

Поддерживает Google Calendar, Apple Calendar (iOS/macOS), Microsoft Outlook и файлы .ICS.

Для рассылок и CRM

Идеально подходит для кнопок в письмах, чат-ботах, мессенджерах и транзакционных уведомлениях.

Динамические переменные

Подстановка персональных имён, кодов и ссылок прямо в описание встречи через параметры ссылки.

2. Как это работает

1
Интерактивный конструктор

Откройте главную страницу, введите название, дату, время, длительность и часовой пояс. Генератор автоматически сформирует готовую ссылку.

2
Страница события (Landing View)

Отправляйте полученную ссылку клиентам. При открытии отображается чистая карточка события с кнопками добавления в любой календарь.

3
Прямые ссылки для кнопок в письме

Если вам не нужна посадочная страница, используйте готовые прямые ссылки на Google, Outlook или Apple, чтобы добавить событие в один клик.

4
Мгновенный файл для Apple (.ics)

Для пользователей iPhone, iPad и Mac доступен эндпоинт /event.ics. При клике iOS сразу открывает нативное окно сохранения события.

3. Синтаксис ссылки

Вы можете формировать ссылки вручную в коде, CRM или скриптах рассылок:

Стандартная ссылка на страницу события:

https://calendarfactory.pages.dev/?title=Встреча&start=2026-11-20T14:00&duration=60&utc=3

Компактная ссылка (короткие параметры):

https://calendarfactory.pages.dev/?t=Встреча&s=2026-11-20T14:00&dur=60&u=3

Прямая ссылка на файл календаря Apple (.ICS):

https://calendarfactory.pages.dev/event.ics?title=Встреча&start=2026-11-20T14:00&duration=60

4. Справочник параметров URL

Параметр Алиас Пример Описание
title t Встреча команды Обязательный. Название мероприятия в календаре.
start s, date, d, dt, datetime 2026-11-20T14:30 Дата и время начала события. Поддерживает ISO 8601, европейский формат (20.11.2026), Unix timestamp ({date:U}), RFC 2822 ({date:r}) или только дату для событий на весь день.
time tm, hour, event_time 14:30, 2:30 PM Время начала при раздельной передаче даты и времени (например, date=2026-11-20&time=14:30).
duration dur 60, allDay Длительность в минутах (15, 30, 45, 60, 90, 120) или allDay. По умолчанию 60 мин.
end e, dtend, finish 2026-11-20T15:30 Время окончания события (если нужно передать конкретное время вместо duration).
utc u, tz 3, -5, 2:00 Смещение часового пояса относительно UTC. Поддерживаются числа (3) или названия городов.
desc d План встречи... Текст описания мероприятия. Безопасный лимит всей ссылки: 2000 символов.
loc l Zoom / Офис Место встречи: физический адрес или ссылка на онлайн-конференцию (Zoom, Google Meet).
banner img, b https://site.com/img.jpg Прямая ссылка на баннер или обложку события 970×250 (JPG, PNG, WebP, GIF, SVG).
theme None dark, light Тема оформления страницы события. По умолчанию light.
c color 1f1f21, ffffff Пользовательский HEX-код цвета фона страницы (без решётки или с ней).
lang None ru, en, ua Язык интерфейса посадочной страницы события.
{переменные} None &name=Алексей Динамические плейсхолдеры: {name} в описании или названии заменяется на значение из &name=....

5. Примеры использования

Онлайн-вебинар с Zoom

Событие с указанием ссылки на Zoom в месте проведения и описанием:

https://calendarfactory.pages.dev/?title=Webinar&start=2026-11-25T19:00&duration=90&utc=3&loc=https://zoom.us/j/123456789&desc=Ссылка+на+материалы+внутри

Персонализированная рассылка (Email)

Использование динамических переменных сервиса рассылки:

https://calendarfactory.pages.dev/?title=Консультация&start=2026-12-01T11:00&desc=Привет,+{name}!+Твой+билет:+{ticket}&name=Алексей&ticket=A-402

Чат-боты (ManyChat / Smart Sender)

Генерация ссылки в кнопке бота через переменные платформы:

https://calendarfactory.pages.dev/?title=Консультация&start={date:c}&duration=45&desc=Привет,+[first_name]!
