# CalendarFactory 🗓️

Простой, быстрый и бесплатный сервис для генерации ссылок на добавление событий в **Google Calendar**, **Apple Calendar**, **Microsoft Outlook** и скачивания универсальных файлов **.ICS**.

Вся информация о событии передается прямо через параметры в URL. Работает без регистрации, серверов и баз данных.

👉 **Онлайн-генератор:** [https://calendarfactory.pages.dev](https://calendarfactory.pages.dev)

---

## 🚀 Как пользоваться

Вы можете:
1. Зайти на [calendarfactory.pages.dev](https://calendarfactory.pages.dev) и создать ссылку через удобную форму.
2. Либо сразу сформировать нужный URL вручную (для писем, ботов, сайтов и рассылок), используя параметры ниже.

При переходе по сформированной ссылке открывается чистая карточка события с кнопками добавления в календарь.

---

## 📋 Параметры URL

Все параметры передаются в строке запроса (`?параметр=значение`) через знак `&`.

| Параметр | Алиасы | Обязательный | Формат / Значения | Описание |
| :--- | :--- | :---: | :--- | :--- |
| **`title`** | `t`, `summary` | **Да** | Текст | Название события. Пример: `title=Встреча+команды` |
| **`start`** | `s`, `date`, `dt` | **Да** | `YYYY-MM-DDTHH:mm`<br>или `YYYY-MM-DD` | Дата и время начала. Без секунд и Z. Для событий на весь день укажите только дату: `2026-11-20`. |
| **`duration`** | `dur` | Нет | Число или `allDay` | Длительность в минутах (`15`, `30`, `45`, `60`, `90`, `120`) или `allDay`. По умолчанию: `60`. |
| **`end`** | `e`, `dtend` | Нет | `YYYY-MM-DDTHH:mm` | Время окончания (если нужно указать конкретное время вместо `duration`). |
| **`utc`** | `u`, `tz` | Нет | Число или город | Смещение часового пояса от UTC (`3`, `+2`, `-5`, `Europe/Kyiv`, `America/New_York`). |
| **`desc`** | `d`, `details` | Нет | Текст | Описание встречи или повестка. Поддерживает перенос строки `\n`. |
| **`loc`** | `l`, `location` | Нет | Текст или ссылка | Место встречи: ссылка на Zoom/Google Meet или физический адрес. |
| **`allDay`** | `allday` | Нет | `1` или `true` | Флаг события на весь день. |
| **`theme`** | — | Нет | `dark` \| `light` | Тема оформления карточки (`dark` для темной темы). |
| **`c`** | `color` | Нет | HEX-код цвета | Произвольный цвет фона страницы (`0f172a`, `ffffff`). |
| **`lang`** | — | Нет | `en` \| `ru` \| `ua` | Язык интерфейса карточки события. |
| **`{переменные}`** | Любое имя | Нет | Текст | Значение подставляется в `{имя}` внутри `title`, `desc` и `loc`. |

---

## 🧩 Динамические переменные (для рассылок и ботов)

В описании (`desc`), названии (`title`) и месте встречи (`loc`) можно использовать плейсхолдеры `{name}`, `{ticket}` и любые другие.

Если добавить одноименный параметр в URL (например, `&name=Алексей`), он автоматически подставится в текст:

```text
https://calendarfactory.pages.dev/?title=Встреча+с+{name}&start=2026-11-20T14:00&duration=45&loc={zoom}&desc=Привет,+{name}!+Твой+билет:+{ticket}&name=Алексей&ticket=VIP-777&zoom=https://zoom.us/j/123456
```

## 💡 Примеры готовых ссылок

### 1. Онлайн-встреча в Zoom (длительность 90 минут, UTC+3)
```text
https://calendarfactory.pages.dev/?title=Webinar+Sync&start=2026-11-25T19:00&duration=90&utc=3&loc=https://zoom.us/j/123456789&desc=Ссылка+на+материалы+внутри
```

### 2. Событие на весь день (Конференция / День рождения)
```text
https://calendarfactory.pages.dev/?title=Design+Conference&start=2026-12-05&duration=allDay&loc=Online&desc=Ежегодная+конференция
```

### 3. Ссылка с тёмной темой и фирменным цветом фона
```text
https://calendarfactory.pages.dev/?title=Product+Launch&start=2026-11-30T17:00&duration=60&theme=dark&c=0f172a&loc=YouTube+Live
```

### 4. Персонализированное напоминание
```text
https://calendarfactory.pages.dev/?title=Консультация+{name}&start=2026-11-22T11:00&duration=30&desc=Здравствуйте,+{name}!+Ждем+вас.&name=Мария
```
