# CalendarFactory 🗓️

Легкий и минималистичный одностраничный сервис для генерации и добавления событий в календари через URL-параметры. 100% Client-side, без бэкенда, без вебхуков и без сторонних трекеров.

Развернут на **Cloudflare** (Cloudflare Pages / Workers Static Assets).

---

## ⚡️ Быстрый старт

Пример ссылки с минималистичным форматом даты (`YYYY-MM-DDTHH:mm`) и динамической переменной:
```text
https://<your-domain>/?title=Launch+Party&start=2026-10-25T15:00&end=2026-10-25T16:30&loc=Online&desc=Welcome+{var},+your+code+is+{code}!&var=test&code=9876
```

### Поддерживаемые календари
- **Google Calendar** (прямая web-ссылка с предзаполнением)
- **Apple Calendar** (генерация и загрузка `.ics` файла через Blob, открытие в 1 клик на iOS/macOS)
- **Microsoft Outlook & Office 365** (прямой deep-link)
- **Universal iCS** (стандарт RFC 5545 для любого мобильного или десктопного календаря)

## 📋 Упрощенный набор параметров URL

### 1. Время старта и окончания (Минималистичный формат)
- `start` (или `s`, `dtstart`) — **Обязательный**. Передается строго в формате без секунд и буквы `Z`:
  `2026-10-25T15:00` (для событий на весь день: `2026-10-25`).
- `end` (или `e`, `dtend`) — Время окончания в аналогичном формате:
  `2026-10-25T16:00`.
- `duration` (или `dur`, `d`) — Альтернатива `end`: длительность в минутах (по умолчанию `60`).

### 2. Динамические переменные в `desc` (Плейсхолдеры)
Любой переданный в URL параметр автоматически подставляется в текст описания (`desc`), а также в `title` и `loc`:
- Если в URL передано `var=test`, то плейсхолдеры `{var}`, `{{var}}`, `%var%` или `${var}` в `desc` заменяются на `test`.
- Можно передавать любое количество произвольных переменных: `&name=Alex&role=Speaker&ticket=VIP`.
- Пример:
  - URL: `?title=Webinar&start=2026-10-25T15:00&desc=Привет+{name},+твой+билет:+{ticket}&name=Dima&ticket=777`
  - Результат в описании: `Привет Dima, твой билет: 777`

### 3. Остальные параметры:
- `title` (или `t`, `summary`) — Название события (`Team+Sync`)
- `loc` (или `location`, `venue`) — Локация (Zoom, Google Meet, адрес)
- `tz` (или `timezone`) — Часовой пояс IANA (`Europe/Kyiv`) — опционально
- `allDay` (или `allday`) — Флаг события на весь день (`1` или `true`)

## 🛠 Разработка и Деплой на Cloudflare

```bash
# Установка зависимостей
pnpm install

# Запуск локального сервера Cloudflare
pnpm dev

# Деплой в Cloudflare Pages
pnpm pages:deploy
```
