# CalendarFactory 🗓️

Легкий и минималистичный одностраничный сервис для генерации и добавления событий в календари через URL-параметры. 100% Client-side, без бэкенда, без вебхуков и без сторонних трекеров.

Развернут на **Cloudflare Pages** (бесплатный домен `*.pages.dev`, глобальный Edge CDN, автоматический SSL).

---

## ⚡️ Быстрый старт

Пример ссылки с минималистичным форматом даты (`YYYY-MM-DDTHH:mm`), кастомным цветом фона (`c=0f172a`) и динамическими переменными:
```text
https://<project-name>.pages.dev/?title=Launch+Party&start=2026-10-25T15:00&end=2026-10-25T16:30&c=0f172a&loc=Online&desc=Welcome+{var},+your+code+is+{code}!&var=test&code=9876
```

### Поддерживаемые календари
- **Google Calendar** (прямая web-ссылка с предзаполнением)
- **Apple Calendar** (генерация и загрузка `.ics` файла через Blob, открытие в 1 клик на iOS/macOS)
- **Microsoft Outlook & Office 365** (прямой deep-link)
- **Universal iCS** (стандарт RFC 5545 для любого мобильного или десктопного календаря)

## 🚀 Деплой на Cloudflare Pages (100% Бесплатно)

Поскольку репозиторий уже опубликован на GitHub (`DamianDream/calendarfactory`), подключение к Cloudflare Pages занимает 1 минуту:

1. Откройте **[dash.cloudflare.com](https://dash.cloudflare.com/)** и перейдите в раздел **Compute (Workers & Pages)** -> **Workers & Pages**.
2. Нажмите **Create application** -> перейдите на вкладку **Pages**.
3. Нажмите **Connect to Git** и выберите репозиторий `DamianDream/calendarfactory`.
4. На странице настроек сборки (Set up builds):
   - **Project name:** `calendarfactory` (будет доступен по адресу `https://calendarfactory.pages.dev`)
   - **Production branch:** `main`
   - **Framework preset:** `None`
   - **Build command:** *(оставить пустым)*
   - **Build output directory:** `public`
5. Нажмите **Save and Deploy**.

Через 15 секунд сайт активен в глобальной сети Cloudflare с бесплатным HTTPS-сертификатом и автоматическим обновлением при каждом новом коммите в ветку `main`!

## 📋 Упрощенный набор параметров URL

### 1. Время старта и окончания (Минималистичный формат)
- `start` (или `s`, `dtstart`) — **Обязательный**. Формат без секунд и Z: `2026-10-25T15:00` (для событий на весь день: `2026-10-25`).
- `end` (или `e`, `dtend`) — Время окончания: `2026-10-25T16:00`.
- `duration` (или `dur`, `d`) — Альтернатива `end`: длительность в минутах (по умолчанию `60`).

### 2. Управление фоном сайта (`color=` или `c=`)
- `c=0f172a`, `c=ffffff`, `color=navy`
- **Адаптивная контрастность:** сайт автоматически определяет яркость фона и переключает карточки и текст между темным и светлым режимами.

### 3. Динамические переменные в `desc` (Плейсхолдеры)
Любой переданный в URL параметр автоматически подставляется в текст описания (`desc`), `title` и `loc`:
- Плейсхолдеры `{var}`, `{{var}}`, `%var%`, `${var}` заменяются на значение из `var=значение`.
- Пример: `?desc=Привет+{name},+билет:+{ticket}&name=Dima&ticket=777` -> `Привет Dima, билет: 777`.

### 4. Конструктор (без параметров):
При открытии корневого адреса без параметров отображается интерактивный интерфейс, который на лету генерирует как ссылку CalendarFactory, так и прямые ссылки на Google/Outlook/Apple календари с кнопками моментального копирования.
