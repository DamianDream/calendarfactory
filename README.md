## ✨ Возможности и преимущества

- **100% Client-side архитектура**: Никаких серверов, баз данных или сторонних сервисов. Вся обработка происходит прямо в браузере пользователя за миллисекунды.
- **Два режима в одном**:
  - Интерактивный генератор с предпросмотром ссылки и генерацией прямых ссылок для писем и ботов.
  - Минималистичная страница приглашения на событие с фокусом на контенте.
- **Поддержка всех ключевых календарей**: Google Calendar, Microsoft Outlook Web, Apple Calendar (через нативный `.ics`), универсальный стандарт RFC 5545 iCalendar.
- **Умная подстановка параметров**: Поддержка алиасов (коротких имен параметров), автоматический расчет времени окончания (`end` или `duration`), смещений часовых поясов (`utc`).
- **Персонализация и рассылки**: Динамические плейсхолдеры `{name}`, `{ticket}` и любые другие переменные для автоматической подстановки данных из CRM/рассыльщиков.
- **Адаптивные темы оформления**: Светлая и тёмная темы, а также поддержка произвольного HEX-цвета фона с автоматическим вычислением контрастности.
- **Мультиязычность**: Встроенная поддержка английского (`en`), украинского (`ua`) и русского (`ru`) языков с автоопределением по языку системы/браузера.
- **Стандарт дизайна Hallmark (Anti-AI-Slop)**: Тактильные keycap-кнопки, токенизированная палитра OKLCH, соблюдение контрастности WCAG AAA, плавная адаптивная сетка без дерганий.

## 🧭 Режимы работы

### 1. Режим конструктора (без параметров)
При открытии корневого адреса `https://calendarfactory.pages.dev` открывается интерактивный конструктор:
- Вводите название, дату и время начала, длительность, часовой пояс, место встречи и описание.
- Ссылка на событие генерируется на лету в реальном времени.
- **Быстрое копирование ссылки**: Кнопка моментального копирования готового URL со всплывающим тултипом без смещения интерфейса.
- **Прямые ссылки в календарь**: Если вам нужно вставить кнопку «Добавить в Google Calendar» или «Скачать .ICS» прямо в письмо, Telegram-бота или Notion — блок прямых ссылок позволяет скопировать готовую ссылку в один клик.

### 2. Режим посадочной страницы (с параметрами)
При переходе по ссылке, содержащей параметры (например, `?title=Team+Sync&start=...`), сайт переключается в режим карточки события:
- Отображаются только ключевые детали: название, дата, время, часовой пояс, место проведения и описание.
- Кнопки быстрого добавления в Google Calendar, Outlook, Apple Calendar или загрузки файла `.ics`.
- Ничего лишнего: шапка конструктора и вспомогательные панели скрываются, не отвлекая пользователя от добавления события.

## 🗓 Поддерживаемые календари

| Календарь | Способ добавления | Особенности |
| :--- | :--- | :--- |
| **Google Calendar** | Прямая веб-ссылка | Моментальное открытие окна создания события в Google Календаре со всеми заполненными полями. |
| **Microsoft Outlook** | Прямая веб-ссылка | Совместимо с Outlook Web и Office 365 (`outlook.live.com` / `outlook.office.com`). |
| **Apple Calendar** | Генерация Data URI / Blob | Автоматическая загрузка `.ics` файла, распознаваемого Apple Calendar на macOS и iOS. |
| **Универсальный .ICS** | Файл стандарта RFC 5545 | Подходит для любого почтового клиента и календаря (Thunderbird, Fastmail, Proton Calendar, Android). |

## 📐 Полный справочник URL-параметров

Все параметры события можно передавать в URL в строке запроса (`?param=value`) или хэше (`#param=value`).

| Параметр | Алиасы | Обязательный | Формат / Допустимые значения | Описание |
| :--- | :--- | :---: | :--- | :--- |
| **`title`** | `t`, `summary` | **Да** | Текст | Название мероприятия в календаре. Пример: `title=Встреча+команды` |
| **`start`** | `s`, `date`, `dt`, `dtstart` | **Да** | `YYYY-MM-DDTHH:mm` или `YYYY-MM-DD` | Дата и время старта. Секунды и символ `Z` не требуются. Для событий на весь день укажите только дату (`2026-11-20`). |
| **`duration`** | `dur` | Нет | Число в минутах или `allDay` | Длительность события в минутах (`15`, `30`, `45`, `60`, `90`, `120`). По умолчанию: `60`. |
| **`end`** | `e`, `dtend` | Нет | `YYYY-MM-DDTHH:mm` | Точное время завершения события (альтернатива параметру `duration`). |
| **`utc`** | `u`, `tz`, `timezone` | Нет | Число (смещение) или IANA-строка | Смещение часового пояса относительно UTC (`3`, `+2`, `-5`, `Europe/Kyiv`, `America/New_York`). |
| **`desc`** | `d`, `description`, `details` | Нет | Текст (до 2000 символов) | Подробное описание или повестка встречи. Поддерживает переводы строк `\n` и плейсхолдеры. |
| **`loc`** | `l`, `location`, `venue` | Нет | Текст или URL | Место встречи: ссылка на Zoom/Google Meet или физический адрес. |
| **`allDay`** | `allday` | Нет | `1` или `true` | Флаг события на весь день. |
| **`theme`** | — | Нет | `dark` \| `light` | Тема оформления карточки. По умолчанию: `light`. |
| **`c`** | `color`, `bg` | Нет | HEX-код цвета (`0f172a`, `ffffff`) | Пользовательский цвет фона. Контраст текста и карточки адаптируется автоматически. |
| **`lang`** | — | Нет | `en` \| `ru` \| `ua` | Язык интерфейса посадочной страницы. |
| **`{переменные}`** | Любое имя | Нет | Текст | Произвольные параметры подставляются в `{имя}` внутри `title`, `desc` и `loc`. |

## 🧩 Динамические шаблоны и переменные

В полях описания (`desc`), названия (`title`) и места встречи (`loc`) можно использовать плейсхолдеры в фигурных скобках:
- `{name}`
- `{{name}}`
- `%name%`
- `${name}`

При формировании URL передайте одноименный GET-параметр, и CalendarFactory автоматически подставит значение в текст!

### Пример персонализированной ссылки для email-рассылки:
```text
https://calendarfactory.pages.dev/?title=Встреча+с+{name}&start=2026-11-20T14:00&duration=45&loc={zoom_link}&desc=Привет,+{name}!+Твой+код+доступа:+{ticket}&name=Алексей&ticket=VIP-9941&zoom_link=https://zoom.us/j/987654321
```

**Результат при переходе:**
- Название: **Встреча с Алексей**
- Место встречи: **https://zoom.us/j/987654321**
- Описание: **Привет, Алексей! Твой код доступа: VIP-9941**

## 💡 Примеры использования

### 1. Онлайн-вебинар с Zoom (90 минут, часовой пояс UTC+3)
```text
https://calendarfactory.pages.dev/?title=Webinar+Architecture&start=2026-11-25T19:00&duration=90&utc=3&loc=https://zoom.us/j/123456789&desc=Ссылка+на+материалы+вебинара+внутри
```

### 2. Событие на весь день (Конференция / День рождения)
```text
https://calendarfactory.pages.dev/?title=Design+Systems+Conf+2026&start=2026-12-05&duration=allDay&loc=Online&desc=Ежегодная+конференция+по+дизайн-системам
```

### 3. Брендированная ссылка с тёмной темой и фирменным цветом фона
```text
https://calendarfactory.pages.dev/?title=Product+Launch&start=2026-11-30T17:00&duration=60&theme=dark&c=0f172a&loc=YouTube+Live
```

### 4. Прямая ссылка для вставки в письмо (Google Calendar)
Если нужно сразу перенаправить пользователя в Google Calendar, ссылка формируется так:
```text
https://calendar.google.com/calendar/render?action=TEMPLATE&text=Team+Sync&dates=20261120T143000Z/20261120T153000Z&details=План+встречи&location=Zoom
```
*(Конструктор CalendarFactory автоматически генерирует и копирует такие ссылки в блоке «Прямые ссылки в календарь»).*

## 🎨 Дизайн и эргономика

CalendarFactory спроектирован по стандарту **Hallmark Anti-AI-Slop**:
- **Токенизация**: Полное отсутствие хардкодных цветов и размеров; все стили построены на CSS-переменных (`--space-*`, `--radius-*`, `--color-*`, OKLCH).
- **Типографика**: Набор системных шрифтов с гармоничной модульной шкалой (`Familjen Grotesk`, `IBM Plex Sans`, моноширинный `JetBrains Mono`).
- **Тактильные кнопки**: Keycap-эффект нажатия, явные состояния `:hover`, `:active` и доступный `:focus-visible` для навигации с клавиатуры.
- **Адаптивность**: Безупречное отображение на мобильных экранах (2 кнопки в ряд) и десктопах (единая строка во всю ширину контейнера).
- **Мягкий отклик**: Копирование ссылок сопровождается плавающими тултипами над кнопками без дергания макета страницы.

## 🛠 Развертывание и локальный запуск

### Локальный запуск
Поскольку проект 100% статичный, запустить его можно любым локальным сервером:

```bash
# Клонировать репозиторий
git clone https://github.com/DamianDream/calendarfactory.git
cd calendarfactory

# Запустить статический веб-сервер (например, встроенный в Python)
python3 -m http.server 8080

# Открыть в браузере
open http://localhost:8080
```

### Развертывание на GitHub Pages
1. Включите **GitHub Pages** в настройках репозитория: `Settings -> Pages`.
2. Выберите ветку `main` и корневую папку `/`.
3. Домен по умолчанию: `https://<username>.github.io/<repo>/` (или подключите собственный домен).

### Развертывание на Cloudflare Pages
1. Подключите репозиторий в панели **Cloudflare Pages**.
2. Укажите каталог сборки: `public` или `/` (в зависимости от настроек).
3. Команда сборки: не требуется (статические файлы).
